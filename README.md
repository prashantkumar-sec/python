# 🐍 Python Learning Journey

My day-by-day journey of learning Python from scratch. I'm a 3rd-year B.Tech CSE student building a strong programming foundation for a career in **networking and cybersecurity**.

This repo holds all my practice code, one step at a time, so I can track progress and revisit concepts later.

## 📁 Repository Structure

```
python/
├── basics/              # Core Python concepts, numbered in learning order
│   ├── 01_basics.py
│   ├── 02_basics.py
│   ├── ...
│   └── 21_basics_py/    # Modules & Packages
└── basics_practice/     # Small projects to apply what I've learned
    └── Password Strength Checker
```

### `basics/`
Files are numbered in the order I learned them (`01_basics.py` onwards), with commits tagged by day (`day-01`, `day-02`, ...). The latest topic is **Modules & Packages**.

### `basics_practice/`
Mini projects built to practice the concepts from `basics/`:

- **Password Strength Checker**: checks how strong a password is.

More projects will be added as I progress.

## 🚀 How to Run

1. Make sure Python 3 is installed:
   ```bash
   python --version
   ```
2. Clone the repo:
   ```bash
   git clone https://github.com/prashantkumar-sec/python.git
   cd python
   ```
3. Run any file:
   ```bash
   python basics/01_basics.py
   ```
