This repo holds all my practice code, one step at a time, so I can track progress and revisit concepts later.

## 🧠 How to Learn From This Repo

This repo is built to be followed in order, like a course. Here is a simple way to get the most out of it:

1. **Follow the commit history.** Commits are tagged by day (`day-01`, `day-02`, ...). Read them from the oldest to the newest to see how each concept builds on the last one.
2. **Read the code, then predict the output.** Before running a file, guess what it will print. If you were wrong, find out why. That gap is where the learning happens.
3. **Run it, then break it.** Change a value, remove a line, pass bad input. See which error appears and fix it. Errors teach more than working code.
4. **Rewrite it from memory.** Close the file and recreate the same program on your own. Compare it with the original and note what you missed.
5. **Extend the small projects.** Take any practice project and add one feature (input validation, saving to a file, a menu). Real skill comes from adding to code, not just reading it.
6. **Connect it to security and networking.** Ask yourself where each concept would be used: parsing logs, checking passwords, automating device config. This keeps the learning practical.
7. **Practice the same topic elsewhere.** After finishing a topic, solve 2-3 problems on HackerRank or LeetCode using that concept.
8. **Learn one thing per day.** One concept, one small program, one commit. Consistency beats long, rare study sessions.

> 💡 Spot a mistake or have a better approach? Open an issue. Feedback is welcome.

## 🚀 How to Run

1. Make sure Python 3 is installed:

```
python --version
```

2. Clone the repo:

```
git clone https://github.com/prashantkumar-sec/python.git
cd python
```

3. Run any Python file:

```
python <file_name>.py
```
